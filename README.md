# Cyberdeck_TD
Cyberdeck Project: Create a cyberdeck based on the LattePanda Mu with a custom carrier board, custom keyboard, built in ~100Wh battery and 11.6" touchscreen.

Keyboard:
- Connect over both Bluetooth and USB (via nRF52840).
- Run ZMK to handle logic and keyboard matrix.
- Built in 1100mAh battery.

LattePanda Mu Custom Carrier Board:
- HDMI output.
- PCIe M-key and E-key.
- 2x USB-A 2.0.
- 2x USB-A 3.1 HSIO ports.

Battery:
- Tenergy 14.4V 7000mAh battery.
- Integrated power path charger in LTC4612 IC to smart switch between USB-C and battery power upon hot-plug.

11.6" Touchscren:
- DFR eDP 11.6" touchscreen.
